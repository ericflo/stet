How these scores were checked

A run is one verifier's machine running a curator on the round's pages, in a sandbox with no network, for up to {{howlong .Scale.EditSeconds}}. It writes an edit script: plain data saying which pieces to keep, in what order.{{if gt $d.RunsPerEntry 1}} Each curator is run by {{$d.RunsPerEntry}} different people when that many are around; runs within {{f2 $d.Tolerance.Run}} bits per byte of each other confirm each other.{{end}}

A grade is a verifier training the model on a script and sitting it on the round's exam. A grade within {{f2 $d.Tolerance.Grade}} bits per byte of the script's gain agrees; the gain is the median of the grades marked counted.

Re-grade any of them yourself:

$ stet score {{if $d.Example}}{{$d.Example}}{{else}}owner/name{{end}} --round {{$d.ID}}
{{end}}
