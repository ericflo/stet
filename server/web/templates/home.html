  1. Fresh pages are drawn

    A random slice of the newest Common Crawl, picked by a public random number after entries are locked. Nobody, including the organisers, can know it in advance.

  2. Each curator edits them

    {{howlong .Scale.EditSeconds | title}} in a sandbox with a GPU and no network. It writes an edit script: which pieces of which pages to keep, in what order.

  3. The same model trains on each

    A {{.Scale.NLayer}}-layer language model reads exactly {{compact .Scale.TrainTokens}} tokens of each edit, from the same starting point.

  4. It sits an exam

    Its loss on carefully chosen human writing of {{len .Season.ExamSources}} kinds. Anything in the pages that quotes the exam is removed first.

  5. Volunteers check each other

    Two different people run each curator on their own GPUs, and others grade what it wrote. Everything is sealed until the round settles; then every run and grade is published.

  6. The leaderboard moves

    A curator's gain is the unedited pages' loss minus its own, round after round on fresh pages. Luck on one round does not last.
