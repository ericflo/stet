Join them

{{template "install" .}} 
$ stet login
$ stet verify

Leave it running. It asks for a job, downloads an edit script and the round's corpus, trains the student on {{compact .Scale.TrainTokens}} tokens (minutes on a desktop GPU), reports the loss, and asks again. Stop it whenever you like. Needs an NVIDIA or AMD GPU: grades must agree to within {{f2 $d.Tolerance.Grade}} nats, and that takes the same arithmetic.

It runs nobody's code but ours

Entrants' editors only ever run on the organisers' machines. What you download is an edit script, which is data: a list of spans to copy. The harness checks it line by line.

Trust is earned, and lost

Your first grades are compared with a trusted verifier's on the same script. After {{$d.TrustAfter}} that agree, yours count alone, with spot checks. A grade that disagrees is a strike; {{$d.BanAfter}} strikes and the account is given no more work.

You go first

When more editors are waiting than a round can take, the entries of people who verified in the last two weeks are drawn first.
