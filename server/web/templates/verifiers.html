Join them

{{template "install" .}} 
$ stet login
$ stet verify

Leave it running. It asks for a job, downloads an edit script and the round's corpus, trains the student on {{compact .Scale.TrainTokens}} tokens (minutes on a desktop GPU), reports the loss, and asks again. Stop it whenever you like. Needs an NVIDIA or AMD GPU: grades must agree to within {{f2 $d.Tolerance.Grade}} nats, and that takes the same arithmetic.

# once established: run the editors too, in a sandbox (Linux)
$ stet verify --edits

An editor has a time limit, so a machine that runs one has to be at least as fast as the season's floor. stet bench measures yours and says.

Grading runs nobody's code but ours

What a grader downloads is an edit script, which is data: a list of spans to copy. The harness checks it line by line. Entrants' programs are a separate job that you ask for, given only to established verifiers and run in a sandbox with no network.

Standing is earned

Every grade is sealed until its round settles. A script's gain is the median of the established verifiers' grades of it, and everyone else's grade is compared with that; the round's page shows every one, whatever it said. After {{$d.EstablishAfter}} grades that agreed, an account is established: its grades count towards scores, and it may run editors. An account whose grades differ {{$d.MuteAfter}} times, and more than once for every ten that agreed, is given no work for {{$d.MuteDays}} days.

Nobody is taken at their word

Each entry is run by {{$d.RunsPerEntry}} different people, and a third when they differ. Nobody runs their own entry, and no volunteer grades a script that only they wrote. The organisers' account is one more verifier: when its machine is the only one there it grades its own runs, and those scores say that they are not confirmed.

You go first

When more editors are waiting than a round can take, the entries of people who verified in the last two weeks are drawn first.
